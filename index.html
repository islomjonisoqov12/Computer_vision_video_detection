Team: Xorazmiy Part A: Event Detection YOLO + ByteTrack + Rule Engine

1. Exploratory Data Analysis & C3896 Sample Observations

Our manual analysis and walkthrough of the sample roadside CCTV footage (`C3896.MP4`) revealed key safety anomalies and traffic patterns:

  • 00:01 — A Cobalt vehicle makes an unsafe turning maneuver.
  • 01:20 — A car blocks the pedestrian path.
  • 3:02 — A car passes through without yielding to waiting pedestrians.
  • 3:06 — Another car executes a turning maneuver near an active traffic light.
  • 3:55 — Onset of localized traffic congestion.
  • 5:13 — A Cobalt vehicle blocks the path of pedestrians.

2. Technical Architecture & Execution Pipeline

Perception & Tracking Logic

  • YOLO Detection: Applied across frames to detect and classify each object in the video stream.
  • Adaptive Frame Sampling: Programmed to process every second or third frame to optimize processing speed and efficiency.
  • ByteTrack Tracking: Tracks each object separately across frames to build clean, distinct trajectory histories.

Rule Engine & Performance

  • Algorithm Evaluation: Once tracked, custom spatial and temporal rules evaluate object movements to flag specific violations.
  • Hardware Profile: On local development hardware processing a 5 GB video sample, the complete detection and analysis run takes approximately 12 minutes.

3. Project Execution Command

The solution integrates seamlessly with the official evaluation harness and is run via the command line:

python run_submission.py --videos ./samples --out predictions_samples.json
